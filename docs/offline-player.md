# 离线播放包（PPT 画册）

公司配置侧栏选择画册 → 点击「下载离线播放包」→ 解压 ZIP → 双击「开始播放.html」。新版画册播放页的浮动工具栏也提供下载按钮。

包内只有自包含 HTML 和使用说明。图片、配置、React 和 PageFlip 均嵌入 HTML，不使用 CDN、不启动服务，不要求 Python/Node，不依赖 5193 端口或局域网 IP。可复制到其他安装现代 Edge/Chrome 的电脑，断网后打开。

默认自动播放和循环开启，保留画册配置中的静止时间、卷页速度及响应式布局。完整载入图片后开始播放；末页循环返回封面。鼠标移动显示控制栏，无操作后隐藏。全屏由用户点击一次或按 F11，不能绕过浏览器的手势限制。

页面图片按原始字节嵌入，没有重新渲染、缩小或重新压缩；ZIP 压缩仅缩减传输体积，不降低清晰度。浏览器仍会按屏幕尺寸等比例显示。离线包是快照，源 PPT 或公司配置变更后需重新下载。

首版不打包视频直链。网络 Logo/背景会明确阻止导出，不悄悄保留网络依赖：请改用本站 public 图片路径、当前画册图片，或清空品牌图片配置。当前图片总量上限为 256MB。请先解压，不在 ZIP 或邮件预览器里直接运行。

## 开发与部署

- `npm run build` 同时生成网页 dist 和离线播放器 offline-dist。
- `npm run build:offline` 单独更新离线播放器。修改播放代码后要重新构建。
- `POST /api/offline-export`，JSON `{tenantId,catalogId}`，返回 ZIP 附件。
- 部署后端时须同时带上 offline-dist/player.js、player.css。
- 离线 HTML 使用 CSP 禁止所有网络连接，只允许内嵌脚本、样式和 data 图片。导出过程限制文件目录，配置字符串经过转义。
- 回归：`python -m unittest test_offline_export test_tenant_store -v`。
