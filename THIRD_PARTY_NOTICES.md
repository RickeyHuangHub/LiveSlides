# Third-party software

LiveSlides uses React, Vite, @vitejs/plugin-react, StPageFlip (page-flip), qrcode, PyMuPDF, Pillow and an installed LibreOffice runtime. JavaScript versions are recorded in package-lock.json; Python versions in requirements.txt.

Each component retains its own copyright and license. Consult the license files distributed with the packages and upstream projects before redistribution. PyMuPDF in particular requires review of applicable licensing terms. This repository does not grant additional rights to dependencies.

Offline HTML embeds player dependencies. Retain the license notices included by the build. Review font and customer-content rights before commercial distribution.

The repository owner has not yet selected a license for LiveSlides itself.
